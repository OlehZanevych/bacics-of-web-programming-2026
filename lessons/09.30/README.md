## Як запустити

Приклади **01, 03 і 04** підключають JS звичайними скриптами з `defer` —
їх можна відкрити прямо з файлу (`file://`), без сервера.

Приклад **02** використовує ES-модулі, а модулі **не працюють через
`file://`** (політика CORS). Його відкривайте через Live Server (VS Code),
вбудований сервер WebStorm (іконка браузера у правому верхньому куті
редактора) або з терміналу:

```bash
npx serve .
```

Якщо все ж відкрити 02 як файл, сторінка покаже червоне попередження
(його виводить окремий звичайний вбудований скрипт, який працює й без сервера).

⚠️ `localStorage` прив'язаний до адреси: дані, збережені через `file://`,
WebStorm (порт 63342) і Live Server (порт 5500), — це три різні сховища.

## 01 і 02: один застосунок — два способи підключення

Код прикладів 01 і 02 майже однаковий — відрізняється лише те, **як файли
знаходять один одного**. Це зручно показати, відкривши обидві версії поруч.

| | `01-user-cards-classic-scripts` | `02-user-cards-es-modules` |
|---|---|---|
| Підключення в HTML | 5 тегів `<script defer>` | 1 тег `<script type="module">` |
| Порядок файлів | **важливий**: `main.js` — останнім | байдужий: `main.js` сам імпортує, що треба |
| Обмін між файлами | глобальний об'єкт `App` (`App.state`, `App.render`…) | `import` / `export` |
| Ізоляція | вручну: код файлу загорнуто в IIFE | автоматично: у кожного модуля своя область видимості |
| Змінні `main.js` | глобальні (у консолі видно `ui`, `form`, `state`) | не видно; `state` відкрито явно як `app.state` |
| Відкриття через `file://` | ✅ працює | ❌ помилка CORS, потрібен сервер |

**Сценарій порівняння (≈ 5 хв):**

1. Відкрити `01…/index.html` подвійним кліком — усе працює.
2. Відкрити `02…/index.html` подвійним кліком — червоне попередження,
   у консолі помилка CORS, кнопки «мертві».
3. Відкрити 02 через сервер — працює так само, як 01.
4. Порівняти `index.html` і перші рядки `main.js` обох версій.
5. У 01 набрати в консолі `ui` — об'єкт видно; у 02 — `ReferenceError`.
6. У 01 перенести `<script src="js/main.js">` на початок списку —
   `App is not defined`: порядок класичних скриптів важливий.

## Картки користувачів — `01-…` / `02-…`

Форма додає користувача в **стан**, стан перемальовує список і зберігається в
`localStorage`. Файли: `state.js` (жодного `document`!), `render.js`,
`storage.js`, `photo.js`, `main.js`.

**Сценарій демонстрації (≈ 15 хв):**

1. «Випадковий» → «Додати». Показати в консолі `Дані форми:` —
   `FormData` + `Object.fromEntries`. Закоментувати `event.preventDefault()`
   у `submit` — сторінка перезавантажується, дані в адресному рядку.
2. Ввести в ім'я лише пробіли → власне повідомлення через `setCustomValidity`.
3. Вибрати фото або **перетягнути файл** на зону — фото стискається через
   `<canvas>` до 96×96 (підпис показує розмір у КБ). Пояснити, чому не можна
   класти оригінал у `localStorage`.
4. ☆ / × на картках — **один** обробник `click` на `<ul>` (делегування,
   `closest('[data-action]')`). Видалення — з анімацією `element.animate()`,
   стан змінюється в події `finish`.
5. Подвійний клік по імені — редагування на місці (`contenteditable="plaintext-only"`,
   `Enter` зберігає, `Esc` скасовує, обробники знімає `AbortController`).
6. Клавіша <kbd>/</kbd> — фокус у пошук (`event.code`, працює і в українській
   розкладці). Пошук — подія `input`, фільтрований список обчислюється, а не
   зберігається.
7. **XSS:** «XSS-атака» → «Додати» — рядок показано як текст. Увімкнути
   «небезпечний рендеринг через innerHTML» — спрацьовує `alert`.
8. Відкрити сторінку в **двох вкладках** і додати користувача — друга вкладка
   оновиться сама (подія `storage`).
9. У консолі: `state.getUsers()` (версія 01) або `app.state.getUsers()` (версія 02);
   `…addUser({ firstName: 'Консоль', lastName: 'Тест', role: 'Студент' })`
   — список оновився без жодного звернення до DOM.

## Подорож події — `03-event-propagation`

На `window`, `document`, `<html>`, `<body>` і чотирьох вкладених блоках —
по обробнику на фазу занурення й на фазу спливання. Обробники лише
**записують** виклики, а після завершення події запис програється покроково:
блоки підсвічуються кольором фази, у журналі — `eventPhase`, `target`,
`currentTarget`, маршрут з `event.composedPath()`. Дублюється в консоль.

**Сценарій (≈ 10 хв):**

1. Клік по «Кнопці» — повний шлях униз і вгору (16 обробників). На цілі
   `eventPhase` = 2 і для capture-, і для bubble-обробника.
2. Клік по «Абзацу» поза кнопкою — ціль змінилася, `target` ≠ `currentTarget`.
3. Вимкнути «обробники фази занурення» — лишається лише спливання
   (так поводиться більшість реального коду).
4. «Зупинити поширення в: `<article>` · спливання» — вище подія не йде.
   Спробувати `<body>` · занурення — подія не дійде навіть до цілі.
5. Увімкнути «ще 2 обробники на `<article>`» — викликаються в порядку
   додавання; з `stopImmediatePropagation()` другий і третій не спрацюють.
6. Повзунок «Пауза між кроками» — сповільнити для пояснення,
   «Повторити» — програти останній клік ще раз.

Налаштування будуються з JS; усі перемикачі обслуговує **один** обробник
`input` на формі, а старі обробники знімаються одним `controller.abort()`.

## Перетягувані вікна — `04-draggable-windows`

«Робочий стіл» з вікнами: перетягування (Pointer Events, `setPointerCapture`,
`AbortController`, `transform`, обмеження межами), підняття нагору, розгортання,
редагування тексту, керування з клавіатури, збереження розкладки в
`localStorage`, `ResizeObserver`. Логіка перетягування — в окремому
файлі `drag.js`, який працює через делегування (один `pointerdown` на всі вікна).

**Сценарій (≈ 15 хв):**

1. Перетягнути вікно — панель під «Лабораторією» показує `clientX/Y`, зсув
   захоплення, позицію, де слухаємо `pointermove`, чи є pointer capture.
2. **Лабораторія** — вимикати по одному (лекція 4, розд. 11.4, 🧪):
   - *зсув захоплення* → вікно «стрибає» кутом під курсор;
   - *clamp* → вікно можна загубити за краєм (повернути — «Упорядкувати»);
   - *document* → усе ще працює, бо є pointer capture;
   - *document* **і** *setPointerCapture* → при швидкому русі вікно
     «губить» курсор, а відпускання поза заголовком — «прилипання».
3. Клавіша <kbd>N</kbd> — нове вікно (`event.code`). <kbd>Tab</kbd> між вікнами
   (`focusin` спливає, `focus` — ні), стрілки / <kbd>Shift</kbd>+стрілки —
   переміщення, <kbd>Enter</kbd> — розгорнути, <kbd>Esc</kbd> — закрити.
4. Подвійний клік по заголовку — розгорнути. «Упорядкувати» — анімація
   `transform` через Web Animations API.
5. Перезавантажити сторінку — розкладка й тексти збереглися. Звузити вікно
   браузера — `ResizeObserver` повертає вікна в межі.

## Що змінилося порівняно з попередніми версіями

| Було (`Temp/…`) | Проблема | Стало |
|---|---|---|
| `onclick="addUser()"`, `onchange` у HTML | змішування розмітки й поведінки | `addEventListener`, делегування |
| `<button type="button">` замість `submit` | не працює Enter, немає валідації | `submit` + `preventDefault` + `FormData` |
| `<img src="">` і перевірка `if (profilePhotoUrl)` | `img.src` порожнього атрибута повертає **адресу сторінки** — умова завжди істинна, у кожній картці «бите» фото | фото зберігається у стані як `null` або data: URL |
| `innerText` / `innerHTML = ''` | повільніше, немає пакетної вставки | `<template>`, `textContent`, `DocumentFragment`, `replaceChildren` |
| форма не очищується, дані зникають після перезавантаження | — | `form.reset()`, `localStorage` з валідацією |
| `<label for="profile-photo">` на `<img>`; поле файлу без підпису | порушення доступності | підписи на полях |
| скрипт у `<head>` без `defer` | працювало лише завдяки inline-обробникам | `defer` (01, 03, 04) або `type="module"` (02) |
| bubbling: `console.log` в inline `onclick` | нічого не видно без консолі | покрокова візуалізація + журнал |
| draggable: `mousedown`/`mousemove` | не працює на сенсорних екранах | Pointer Events |
| `document.onmousemove = …` | перезаписує чужі обробники | `addEventListener` + `AbortController` |
| `e.pageX - rect.left` | `pageX` — від документа, `rect` — від вікна: при прокрутці вікно «їде» | `clientX` з обох боків |
| `modalWindowHeight = offsetWidth` | помилка копіювання — висота береться з ширини | — |
| `'#' + (random * 2^24 \| 0).toString(16)` | 5-значний hex (напр. `#3fa2c`) — **невалідний колір**, прямокутник прозорий | відтінок HSL через CSS-змінну `--hue` |
| `left`/`top` під час руху | перерахунок макета на кожен рух | `transform: translate()` |
| немає меж, закриття, клавіатури | — | clamp, ×, стрілки, Esc, Enter |
